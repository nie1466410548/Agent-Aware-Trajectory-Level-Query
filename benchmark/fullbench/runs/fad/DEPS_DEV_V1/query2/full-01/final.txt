Task: Among all NPM packages with project license 'MIT' and marked as release, which 5 projects have the highest GitHub fork count?

Method:
1. package_database (SQLite): selected distinct NPM package names where Licenses contains "MIT" and VersionInfo has "IsRelease": true -> 10,406 packages.
2. project_database (DuckDB): joined these packages via project_packageversion (System='NPM', ProjectType='GITHUB') to GitHub projects.
3. Fork counts were extracted from project_info.Project_Information text (regex-parsed "N forks" / "forks count of N" / "forked N times" patterns, handling comma separators). 752 of 770 project rows parsed; the 18 unparsed rows were manually verified and all have far fewer forks (max 1,449), so the top 5 is unaffected.

Answer - Top 5 projects by GitHub fork count:
1. mui-org/material-ui - 30,522 forks (e.g., NPM package @docly/web)
2. moment/moment - 7,201 forks
3. lodash/lodash - 7,109 forks
4. semantic-org/semantic-ui - 4,955 forks
5. react-native-elements/react-native-elements - 4,623 forks
