Methodology: From package_database.packageinfo, the latest release version of each distinct
NPM package was determined by the maximum VersionInfo.Ordinal among versions with
IsRelease = true. These (Name, Version) pairs were joined to
project_database.project_packageversion (System='NPM', RelationType='SOURCE_REPO_TYPE')
to find the associated GitHub repository, and star counts were extracted from
project_database.project_info.Project_Information. Synthetic dependency-path entries
(names containing '>') were excluded as they are not real NPM packages.
